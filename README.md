# Thibaut Crépelle Portfolio — 1:1 Interactive Replica

> A pixel-perfect, responsive 1:1 visual and interactive replica of **[thibaut.cool](https://www.thibaut.cool/)**, the portfolio of 3D & Motion freelance designer Thibaut Crépelle. Built with React, Three.js, Framer Motion, and Vite.

---

## ✨ Features

- **📺 Hero Section**:
  - Amstrad CTM 644 retro TV shelf setup with green ASCII 3D TC Monogram powered by Three.js `AsciiEffect` and OrbitControls.
  - Authentic top-to-bottom scanline wipe reveal transition.
  - Lottie headline animation *"Let's make it move."* and ambient emerald glow.
- **💼 Works Showcase ("Cool stuff I've done")**:
  - **Retro Tech Carousel**: MacIntosh 128k, Konica Pop, and Walkman WM-22 with interactive switching, embedded video showcases, and Behance breakdown links.
  - **The Nostalgia Alphabet**: Embedded YouTube video showcase, 1982 edition floppy book shelf render, and Plasticity file download button.
  - **Specify - Web Design**: 3D token engine animation running directly on the laptop display, floating glass token cubes, and project story.
  - **iMac G3 - Web and Motion**: Bondi Blue iMac G3 with CRT browser animation video mapped onto the display.
- **🕹️ About Section ("About Me")**:
  - Studio pegboard with Commodore 64, headphones, polaroids, and water bottle.
  - Integrated vertical dot-matrix display with animated social icons and interactive hover hotspots (Twitter, Instagram, Behance, Email).
- **⌨️ Contact Cyberdeck Console ("Hit me up")**:
  - 1:1 Framer coordinate mapped Cyberdeck console with authentic chassis texture.
  - Glowing green `'Available For Freelance'` LED status bar video.
  - 9 mechanical keycaps with realistic travel animation on hover and click (`HOME`, `G3`, `IG`, `@`, `HIRE ME`, `X`, `CALL ME`, `DB`, `BH`).
  - Circular CRT oscilloscope display with green animated Lissajous TC waveform.
  - Pixel-styled button bracket actions with clipboard copy functionality and toast notifications.
- **🎯 Interactive Polish**:
  - Magnetic dual-ring custom cursor with dynamic hover scaling.
  - Persistent sticky section tracker pill on the side.

## 🛠️ Tech Stack

- **React 18**
- **Vite 6**
- **Three.js** (WebGL 3D monogram & AsciiEffect shader)
- **Framer Motion** (Layout animations, project card transitions)
- **Lottie Web** (SVG headline typography animation)
- **Vanilla CSS** (Curated design tokens, responsive typography)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/bravo0001/portfolio-testing.git

# Navigate to project directory
cd portfolio-testing

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Build

```bash
# Generate production bundle
npm run build

# Preview production build locally
npm run preview
```
